> 版本：v1.0  
> 日期：2026-07-31  
> 对应需求文档：v1.1

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 采集与展示分离 | Collector 只管拿数据，Formatter 只管渲染，互不依赖 |
| 模块独立性 | 每个 Collector 可独立开发、测试、运行，不依赖其他 Collector |
| 容错优先 | 任何单点失败不导致整体崩溃，优雅降级 |
| 可读性优先 | 中文键名 dict，打印即可调试 |
| 渐进增强 | 先保证核心数据正确，再优化格式/性能/扩展 |

## 3. 核心接口定义

### 3.1 BaseCollector（采集基类）

```python
# core/base.py
from abc import ABC, abstractmethod

class BaseCollector(ABC):
    """所有硬件采集模块的基类"""

    # === 类属性（子类必须定义）===
    name: str = ""          # 模块标识符，如 "cpu"、"gpu"（用于命令行和配置）
    label: str = ""         # 中文显示名，如 "处理器"、"显卡"（用于输出标题）
    order: int = 0          # 显示排序权重（越小越靠前）

    @abstractmethod
    def collect(self) -> dict:
        """
        执行硬件信息采集。

        Returns:
            dict: 中文键名的采集结果字典。
                  成功时返回完整数据。
                  如果部分字段获取失败，该字段值设为 None 并在
                  结果中添加 "_警告" 键说明原因。

        Raises:
            CollectorError: 当整个模块完全无法采集时抛出。
        """
        ...

    def get_brief_fields(self) -> list[str]:
        """
        返回 brief 模式下应显示的键名列表。
        子类可覆写，默认返回全部键。
        """
        return []

    def __repr__(self) -> str:
        return f"<{self.__class__.__name__} name={self.name}>"
```

### 3.2 CollectorManager（调度管理器）

```python
# core/manager.py
from dataclasses import dataclass, field
from concurrent.futures import ThreadPoolExecutor, as_completed

@dataclass
class CollectResult:
    """采集结果汇总"""
    data: dict = field(default_factory=dict)       # {"cpu": {...}, "gpu": {...}}
    errors: list[dict] = field(default_factory=list)  # [{"模块": "cpu", "错误": "..."}]
    warnings: list[str] = field(default_factory=list) # ["磁盘SMART需管理员权限"]
    elapsed_seconds: float = 0.0                   # 总耗时

class CollectorManager:
    """采集调度中心"""

    TIMEOUT = 10  # 单模块超时秒数

    def __init__(self):
        self._collectors: dict[str, BaseCollector] = {}

    def register(self, collector: BaseCollector) -> None:
        """注册一个 Collector 实例"""
        self._collectors[collector.name] = collector

    def collect(
        self,
        categories: list[str] | None = None,
        exclude: list[str] | None = None,
    ) -> CollectResult:
        """
        执行采集。

        Args:
            categories: 要采集的类别列表。None 表示全部。
            exclude: 要排除的类别列表。

        Returns:
            CollectResult 包含数据、错误、警告、耗时。
        """
        ...

    def list_collectors(self) -> list[dict]:
        """返回所有已注册 Collector 的 name 和 label"""
        ...
```

### 3.3 Registry（注册机制）

```python
# core/registry.py

_REGISTRY: dict[str, type] = {}

def register_collector(cls):
    """
    装饰器：将 Collector 类注册到全局注册表。
    用法：
        @register_collector
        class CPUCollector(BaseCollector):
            name = "cpu"
            ...
    """
    _REGISTRY[cls.name] = cls
    return cls

def get_all_collectors() -> list[BaseCollector]:
    """实例化并返回所有已注册的 Collector（按 order 排序）"""
    instances = [cls() for cls in _REGISTRY.values()]
    return sorted(instances, key=lambda c: c.order)

def get_collector(name: str) -> BaseCollector | None:
    """按名称获取单个 Collector 实例"""
    cls = _REGISTRY.get(name)
    return cls() if cls else None
```

## 4. 各采集模块详细设计

### 4.1 通用约定

- 每个模块文件位于 `collectors/` 目录
- 使用 `@register_collector` 装饰器自动注册
- WMI 查询通过 `utils.wmi_helper.get_wmi()` 获取共享连接
- 返回 dict 中，获取失败的字段值设为 `None`
- 模块级致命错误抛出 `CollectorError`
- 非致命问题记录到返回 dict 的 `"_警告"` 键

### 4.6 显卡 (gpu.py)

| 项目 | 值 |
|------|-----|
| name | `"gpu"` |
| label | `"显卡"` |
| order | 50 |
| 数据源 | WMI: `Win32_VideoController` + pynvml (N卡) |

**采集逻辑：**
1. 从 WMI 获取所有 `Win32_VideoController` 实例
2. 判断独显/核显：通过 `AdapterCompatibility` + `PNPDeviceID` 中的总线信息
3. 如果是 NVIDIA 且 pynvml 可用，补充负载/显存实时数据
4. 如果是 AMD/Intel，仅使用 WMI 数据

**字段映射：**

| 输出键名 | 数据源 | 处理 |
|----------|--------|------|
| 类型 | 推断逻辑 | "独显" / "核显" |
| 名称 | Win32_VideoController.Name | 直接取值 |
| 厂商 | Win32_VideoController.AdapterCompatibility | 直接取值 |
| 显存_MB | Win32_VideoController.AdapterRAM | int (注：32位WMI可能溢出) |
| 驱动版本 | Win32_VideoController.DriverVersion | 直接取值 |
| 驱动日期 | Win32_VideoController.DriverDate | WMI 时间 → 日期 |
| 当前分辨率 | Win32_VideoController.CurrentHorizontalResolution × Vertical | "2560×1440" |
| 刷新率_Hz | Win32_VideoController.CurrentRefreshRate | int |
| 状态 | Win32_VideoController.Status | "正常"/"已禁用" |
| 负载_百分比 | pynvml (仅N卡) | float 或 None |
| 显存使用_MB | pynvml (仅N卡) | int 或 None |

**返回结构：**

### 4.7 存储设备 (storage.py)

| 项目 | 值 |
|------|-----|
| name | `"storage"` |
| label | `"存储设备"` |
| order | 60 |
| 数据源 | WMI: `Win32_DiskDrive` + `Win32_LogicalDisk` + `Win32_DiskDriveToDiskPartition` |

**采集逻辑：**
1. `Win32_DiskDrive` 获取物理磁盘列表
2. `Win32_DiskDriveToDiskPartition` + `Win32_LogicalDiskToPartition` 关联分区→盘符
3. 通过 `InterfaceType` + PNPDeviceID 判断 SATA/NVMe
4. 通过型号关键词 + PNPDeviceID 推断 SSD/HDD

> **设计决策：不采集 MediaType / HealthStatus**
>
> 这两个字段只能通过 PowerShell `Get-PhysicalDisk` 获取（WMI 无等价接口）。
> PowerShell 进程启动固有开销约 1.5–2s，是整个工具最大的性能瓶颈。
> 且 HealthStatus 需要管理员权限，普通用户下始终返回“需管理员权限”，实用价值低。
> 因此 v0.1 不采集这两个字段，磁盘类型通过关键词 + PNP ID 推断。
> 后续版本可考虑通过配置开关按需启用。

**字段映射（每块磁盘）：**

| 输出键名 | 数据源 | 处理 |
|----------|--------|------|
| 型号 | Win32_DiskDrive.Model | strip() |
| 类型 | 型号关键词 + PNPDeviceID | "SSD" / "HDD" / "未知" |
| 接口 | Win32_DiskDrive.InterfaceType + PNPDeviceID | "NVMe"/"SATA"/"USB" |
| 容量_GB | Win32_DiskDrive.Size | bytes → GB |
| 固件 | Win32_DiskDrive.FirmwareRevision | 直接取值 |
| 序列号 | Win32_DiskDrive.SerialNumber | strip() |
| 分区 | Win32_LogicalDisk 关联 | 列表 |

**返回结构：**
```python
{
    "磁盘列表": [
        {
            "型号": "Samsung SSD 980 PRO 1TB",
            "类型": "SSD",
            "接口": "NVMe",
            "容量_GB": 1000.2,
            ...
            "分区": [
                {"盘符": "C:", "标签": "系统", "文件系统": "NTFS", "已用_GB": 200, "总计_GB": 465.7},
            ]
        },
    ]
}
```

**brief 字段（每块盘）：** `["型号", "类型", "容量_GB"]`

### 4.8 网络设备 (network.py)

| 项目 | 值 |
|------|-----|
| name | `"network"` |
| label | `"网络设备"` |
| order | 70 |
| 数据源 | WMI: `Win32_NetworkAdapter` + `Win32_NetworkAdapterConfiguration` + netsh |

**采集逻辑：**
1. `Win32_NetworkAdapter` 过滤 `PhysicalAdapter=True` 且 `NetConnectionID` 非空
2. 通过 `AdapterType` 或 `PNPDeviceID` 区分有线/无线
3. `Win32_NetworkAdapterConfiguration` 获取 IP/MAC/子网
4. 无线额外信息：`netsh wlan show interfaces` 获取 SSID 和信号

**字段映射（每个网卡）：**

| 输出键名 | 数据源 | 处理 |
|----------|--------|------|
| 类型 | AdapterType / PNPDeviceID | "以太网" / "无线" |
| 名称 | Win32_NetworkAdapter.Name | 直接取值 |
| 厂商 | Win32_NetworkAdapter.Manufacturer | 直接取值 |
| MAC | Win32_NetworkAdapter.MACAddress | 直接取值 |
| 速率_Gbps | Win32_NetworkAdapter.Speed | bps → Gbps |
| 状态 | Win32_NetworkAdapter.NetConnectionStatus | 2="已连接", 其他="未连接" |
| IPv4 | Win32_NetworkAdapterConfiguration.IPAddress[0] | 取第一个 IPv4 |
| 子网掩码 | Win32_NetworkAdapterConfiguration.IPSubnet[0] | 直接取值 |
| 网关 | Win32_NetworkAdapterConfiguration.DefaultIPGateway[0] | 直接取值 |
| SSID | netsh wlan show interfaces (仅无线) | 解析输出 |
| 信号_dBm | netsh wlan show interfaces (仅无线) | 解析百分比→dBm |

**brief 字段（每个网卡）：** `["名称", "状态", "IPv4"]`

| name | `"monitor"` |
| label | `"显示器"` |
| order | 90 |
| 数据源 | WMI: `WmiMonitorID` (root\wmi) + `Win32_VideoController` + `Win32_DesktopMonitor` |

**采集逻辑：**
1. `root\wmi` 命名空间查询 `WmiMonitorID` 获取厂商/型号/制造日期
2. `Win32_VideoController` 获取当前分辨率/刷新率
3. 连接方式：通过注册表 `HKLM\SYSTEM\CurrentControlSet\Enum\DISPLAY\` 或 WMI 关联推断

**字段映射（每个显示器）：**

| 制造年份 | WmiMonitorID → YearOfManufacture | int |
| 制造周 | WmiMonitorID → WeekOfManufacture | int |
| 分辨率 | Win32_VideoController.CurrentHorizontal/VerticalResolution | "2560×1440" |
| 刷新率_Hz | Win32_VideoController.CurrentRefreshRate | int |
| 连接方式 | 注册表/推断 | "DisplayPort"/"HDMI"/"未知" |
| 状态 | 是否当前活动 | "活动"/"未连接" |

```python
import subprocess
import json

def run_powershell(command: str, timeout: int = 10) -> str:
    """
    执行 PowerShell 命令，返回 stdout 文本。

    Args:
        command: PowerShell 命令字符串
        timeout: 超时秒数

    Returns:
        命令输出的文本

    Raises:
        subprocess.TimeoutExpired: 超时
        subprocess.CalledProcessError: 命令执行失败
    """
    result = subprocess.run(
        ["powershell", "-NoProfile", "-NonInteractive", "-Command", command],
        capture_output=True,
        text=True,
        timeout=timeout,
        encoding="utf-8",
    )
    if result.returncode != 0:
        raise subprocess.CalledProcessError(result.returncode, command, result.stderr)
    return result.stdout.strip()

def run_powershell_json(command: str, timeout: int = 10) -> list | dict:
    """
    执行 PowerShell 命令并以 JSON 解析输出。
    命令应包含 '| ConvertTo-Json' 管道。
    """
    output = run_powershell(command, timeout)
    return json.loads(output) if output else {}
```

## 9. 关键实现细节

### 9.1 并行采集与超时

```python
# core/manager.py 核心逻辑

def collect(self, categories=None, exclude=None) -> CollectResult:
    import time
    start = time.perf_counter()

    # 筛选要执行的 collectors
    targets = self._filter_collectors(categories, exclude)

    result = CollectResult()

    with ThreadPoolExecutor(max_workers=len(targets)) as executor:
        future_map = {
            executor.submit(collector.collect): collector
            for collector in targets
        }

        for future in as_completed(future_map, timeout=self.TIMEOUT + 5):
            collector = future_map[future]
            try:
                data = future.result(timeout=self.TIMEOUT)
                result.data[collector.name] = data
            except TimeoutError:
                result.errors.append({"模块": collector.name, "错误": "采集超时"})
            except CollectorError as e:
                result.errors.append({"模块": collector.name, "错误": str(e)})
            except Exception as e:
                result.errors.append({"模块": collector.name, "错误": f"未知错误: {e}"})

    result.elapsed_seconds = round(time.perf_counter() - start, 2)
    return result
```

```python
import os
import sys

def supports_unicode() -> bool:
    """检测终端是否支持 Unicode 框线字符"""
    if os.environ.get("HWINFO_FORCE_ASCII"):
        return False
    # Windows Terminal 设置此环境变量
    if os.environ.get("WT_SESSION"):
        return True
    # 尝试检测代码页
    try:
        return sys.stdout.encoding.lower().replace("-", "") == "utf8"
    except:
        return False

def supports_color() -> bool:
    """检测终端是否支持 ANSI 颜色"""
    if os.environ.get("HWINFO_NO_COLOR"):
        return False
    if os.environ.get("WT_SESSION"):
        return True
    # 尝试启用 Windows VT100 模式
    try:
        import ctypes
        kernel32 = ctypes.windll.kernel32
        handle = kernel32.GetStdHandle(-11)  # STD_OUTPUT_HANDLE
        mode = ctypes.c_ulong()
        kernel32.GetConsoleMode(handle, ctypes.byref(mode))
        # ENABLE_VIRTUAL_TERMINAL_PROCESSING = 0x0004
        return bool(mode.value & 0x0004) or kernel32.SetConsoleMode(handle, mode.value | 0x0004)
    except:
        return False

def force_utf8_stdout():
```

## 10. 错误处理策略

### 10.1 错误分级

| 级别 | 含义 | 处理方式 |
|------|------|----------|
| 致命 (CollectorError) | 整个模块无法工作（如 WMI 服务不可用） | 该模块输出为空，记入 errors |
| 警告 (Warning) | 部分字段获取失败（如权限不足） | 字段值设为 None 或提示文本，记入 warnings |
| 信息 (Info) | 非异常但值得提示（如"以管理员运行更完整"） | 仅在末尾提示 |

### 10.2 Collector 内部错误处理模板

```python
# collectors/storage.py 示例

@register_collector
class StorageCollector(BaseCollector):
    name = "storage"
    label = "存储设备"
    order = 60

    def collect(self) -> dict:
        warnings = []
        disks = []

        try:
            c = get_wmi()
            drives = c.Win32_DiskDrive()
        except Exception as e:
            raise CollectorError(self.name, f"无法访问磁盘信息: {e}")

        for drive in drives:
            disk_info = {
                "型号": (drive.Model or "").strip(),
                "容量_GB": bytes_to_gb(int(drive.Size)) if drive.Size else None,
                ...
            }

            # SMART 数据 - 可能因权限失败
            try:
                disk_info["健康状态"] = self._get_smart_status(drive)
            except PermissionError:
                disk_info["健康状态"] = "需管理员权限"
                warnings.append(f"{disk_info['型号']} SMART 数据需管理员权限")

            disks.append(disk_info)

        result = {"磁盘列表": disks}
        if warnings:
            result["_警告"] = warnings
        return result
```
